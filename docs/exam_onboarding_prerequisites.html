Exam Onboarding Prerequisites

Everything we need from you to monitor an exam with CCTV analytics, and the exact Excel layout our system accepts for each file. The examples use the real files from SSC CGL 2026, so you can compare your sheet column by column.

00

What to send

Which files you need depends on how your cameras are delivered. RTSP exams stream from DVR servers (for example Camview). HLS exams stream web video links (.m3u8) per lab and shift.

The TC code ties everything together. The centre schedule, the camera list, the server room limits and the SMS numbers are matched to each other by TC code alone. Use the same TC code for a centre in every file, written exactly the same way.

02

Exam date & shift schedule

RTSPHLSRequired

One row per exam date, one column per shift, Yes or No in each cell. For RTSP exams, a date + shift marked No (or a date missing from the sheet) means no camera is monitored then. For HLS exams the sheet sets up the exam's dates and shifts; which cameras run is decided by the camera upload for that shift and date.

  • Date: 30-Sep-26, 30-09-2026, 2026-09-30 or an Excel date cell.
  • Shift header: Shift N (HH:MM:SS to HH:MM:SS). "Shift N" is matched to the exam's Nth shift.
  • Cells: Yes or No.
  • List every exam date. A date that's missing counts as "the exam does not run".
Write afternoon times in 24-hour form. The current SOP sheet says Shift 2 (01:30:00 to 02:30:00) and Shift 3 (05:00:00 to 06:00:00) for 13:30 and 17:00. Our system flags times before 06:00 because they may mean the middle of the night. Please write 13:30:00 and 17:00:00.

  • TC CODE: exactly as in the camera list. Codes are read as text, so 50106.0 becomes 50106 and 351603_1 stays as it is.

Keep header spacing clean. Nine headers in the current sheet have a double space (15-10-26 Shift  3). They're accepted, but single spaces avoid mismatches.

SMS observer numbers

RTSPHLSIf SMS alerts are wanted

When your team accepts an alert on the client dashboard, an SMS goes to the numbers listed for that alert's centre. Two columns: the TC code and a mobile number.

  • One number per row; repeat the TC code for each extra number. Several numbers in one cell separated by commas also work.
  • 10-digit mobile numbers. +91, spaces and dashes are removed automatically.
  • Accepted headers include TC Code / Centre Code and Mobile Number / Contact Number / Phone.

The current SSC CGL sheet has 557 rows for 160 centres (1 to 5 numbers each). Every number is valid, and every centre with cameras has at least one. 55 rows are exact repeats; we ignore them, but you can remove them.

Analytics plan

RTSPHLSRequired

Tell us which analytics to run, on which camera types, and in which time window around each shift. You can send it as a table in your SOP or in the sheet below; our team enters it on the schedule screen.

Before you send

Templates. Blank templates for the exam schedule, centre-wise schedule and server room limits can be downloaded from the Exams page; RTSP and HLS camera templates from the Cameras page. Every upload is checked, and problems (an unknown shift, a bad cell value, a time that looks like night) are reported by row.
Prepared by CDIS for client onboarding. Formats match the system's accepted uploads as of October 2026; examples are taken from the SSC CGL 2026 files.
