Overview

Four read-only GET endpoints give you the cameras, camera types, detection event types and current schedule for SSC Combined Graduate Level Examination 2026. All responses are JSON.

ItemValue
Base URLhttp://examscctvmonitoring.com/cctv_analytics
MethodGET (all endpoints)
Response formatapplication/json
ScopeOne exam only: SSC Combined Graduate Level Examination 2026
Vendorvendor_name = CDIS in every response

Data is live: camera types and statuses change as cameras are classified and come online during the exam.

Authentication

Every request must send the API key in the Authorization header as a Bearer token. Requests without it, or with a wrong key, get 401 Unauthorized.

Header

Authorization: Bearer <API_KEY>

API key

The API key is provided separately by CDIS. Keep it confidential and use it only from your servers. It does not expire; contact CDIS if it needs to be rotated.

Example request

curl -H "Authorization: Bearer <API_KEY>" \
  http://examscctvmonitoring.com/cctv_analytics/api/v1/master/camera-types

All paths are relative to the base URL. None take query parameters.
